## [阿里 AI 模型下载量突破 30 亿，超越 Meta 与谷歌](https://www.bloomberg.com/news/articles/2026-08-15/alibaba-ai-models-hit-3-billion-downloads-passing-meta-google) ⭐️ 9.0/10

阿里巴巴的开放权重 AI 模型，主要是 Qwen 系列，在短短六个月内全球下载量已超过 30 亿次，超过了 Meta 的 2.27 亿次和谷歌的 4.18 亿次下载量。 这一里程碑表明开放权重模型正成为主流，开发者获得更广泛的访问权限，可能加速创新，但也引发了治理和滥用的担忧。 阿里已发布超过 460 个基础 Qwen 模型以及超过 30 万个衍生版本，其中 Qwen 3.8‑Max 2.4 万亿参数模型的权重已公开。

telegram · zaihuapd · 8月15日 15:18

**背景**: 开放权重模型是指其训练权重公开发布，任何人都可以下载、运行并在个人硬件上微调的 AI 模型。阿里巴巴的 Qwen 系列是由阿里云研发的大型语言模型（LLM）和多模态模型（LMM），最新的 Qwen 3.8‑Max 于 2026 年 7 月发布。Hugging Face 聚合模型下载统计，为跨供应商比较模型受欢迎程度提供基准。

## [X1 示范机完成首飞，电费仅 5 美元](https://arstechnica.com/gadgets/2026/08/first-test-flight-of-largest-all-electric-aircraft-used-just-5-of-electricity/) ⭐️ 8.0/10

## [Codex 自动研究实现 GPU 核心 232 倍加速](https://sankalp.bearblog.dev/autoresearch/) ⭐️ 7.0/10

作者利用 OpenAI Codex 自动化研究、分析并重构 GPU 核心，最终实现了原实现的 232 倍加速。该过程通过 AI 生成的代码修改与分析反馈循环完成。 这一显著加速展示了 AI 代理在低层性能工程中的实际潜力，显著降低了手动调优时间，并提升了 GPU 工作负载效率。它还表明 auto‑research 框架能加速核心开发周期。 优化主要依赖 Codex 生成 CUDA 代码片段，并通过分析数据引导代理关注内存合并、指令吞吐量和共享内存使用。最终核心经过人工验证，确保在多样输入下的正确性。

hackernews · tosh · 8月15日 11:00 · [社区讨论](https://news.ycombinator.com/item?id=49309549)

**背景**: OpenAI Codex 是一个基于数十亿行公开代码训练的代码生成模型，常用于 GitHub Copilot 帮助开发者。GPU 核心优化通常需要调节内存访问模式、指令调度，并利用共享内存和 warp 并行等硬件特性。Karpathy 的 AutoResearch 等 auto‑research 框架通过自动化实验循环，让 AI 代理提出、训练、评估并仅保留改进。

## [Firefox 成为唯一主流浏览器支持 uBlock Origin](https://zeli.app/zh/digest/2026-08-14) ⭐️ 7.0/10

Firefox 宣布将继续支持流行的广告拦截扩展 uBlock Origin，成为唯一主流浏览器在 Chromium 迁移到 Manifest V3 后仍支持该扩展的浏览器。同一周，Qwen 系列发布了 270 亿参数的 Qwen3.8‑27B 视觉‑语言模型，并开放权重。 此举维护了依赖广告拦截的用户的隐私工具，而开放的 AI 模型则为需要高性能视觉‑语言能力的开发者提供了更多研究和部署选择。 Manifest V3 限制扩展对关键 API 的访问，削弱了广告拦截器；Firefox 的实现避免了这些限制。Qwen3.8‑27B 原生支持 256K 上下文标记，并可与 vLLM 等框架一起部署，便于本地使用。

rss · Zeli · 8月14日 23:59

**背景**: Manifest V3 是 Chromium 浏览器最新的扩展平台，引入了基于服务工作者的架构和更严格的 API 访问，以提升安全性和性能。uBlock Origin 是广泛使用的广告拦截扩展，依赖这些 API 来过滤请求。Qwen 系列由阿里巴巴开发，提供稠密的视觉‑语言模型；27B 变体是迄今为止最大的公开模型，并以 Apache 2.0 开源。
