## [Firefox Remains Only Major Browser Supporting uBlock Origin](https://zeli.app/zh/digest/2026-08-14) ⭐️ 7.0/10

Firefox has announced it will continue to support the popular ad‑blocking extension uBlock Origin, becoming the sole major browser to do so as Chromium browsers transition to Manifest V3. In the same week, the Qwen family released the 27‑billion‑parameter Qwen3.8‑27B vision‑language model as open weights. The move preserves a robust privacy tool for users who rely on ad‑blocking, while the open‑source AI model expands research and deployment options for developers needing high‑performance vision‑language capabilities. Manifest V3 limits extensions’ access to key APIs, which weakens ad‑blockers; Firefox’s implementation avoids these restrictions. Qwen3.8‑27B supports up to 256K context tokens natively and can be served with frameworks like vLLM, making local deployment practical.

rss · Zeli · Aug 14, 23:59

**Background**: Manifest V3 is the latest extension platform for Chromium browsers, introducing service‑worker‑based architecture and stricter API access to improve security and performance. uBlock Origin is a widely used ad‑blocking extension that relies on these APIs to filter requests. The Qwen series, developed by Alibaba, provides dense vision‑language models; the 27B variant is the largest released to date and is open‑source under Apache 2.0.
