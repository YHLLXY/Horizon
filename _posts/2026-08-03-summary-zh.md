## [香港推出中国国债期货](https://36kr.com/newsflashes/3923229176016521?f=rss) ⭐️ 9.0/10

2026 年 8 月 3 日，香港交易所上市首个离岸中国国债期货（5 年期 CGB），为全球投资者提供对冲在岸利率风险的工具。 此举扩大了全球投资者对中国主权债市的准入，提升了流动性和定价效率，并通过离岸对冲与投资加速了人民币国际化。 该期货在香港交易、结算，使用现有离岸账户，绕过 QFII 配额限制，价格以人民币计价，直接连接在岸与离岸市场。

rss · 36氪 · 8月3日 03:15

**背景**: 中国债券市场是全球第二大，但截至目前，外国投资者只能通过合格境外机构投资者（QFII）方案在岸交易。债券期货是衍生合约，允许投资者锁定未来利率，降低市场波动风险。离岸债券期货为全球投资者提供了一个便捷、受监管的场所，既可对冲也可投机，而无需在岸准入。

## [OpenAI Astra 以 2000 美元算力成本破解十项数学难题](https://36kr.com/newsflashes/3923212228292232?f=rss) ⭐️ 9.0/10

OpenAI 宣布其下一代模型 Astra 在内部版本中解决了十项长期存在的数学和理论计算机科学难题，估计使用约 2000 美元的 token 成本完成。 这表明大型语言模型现在能够以极低的算力成本完成深度数学证明，可能加速研究并降低学术与工业界的门槛。 突破包括高维球体堆积密度上限、二进制与球面码界限提升、非纯索菲群存在性证明、康涅斯刚性猜想的推翻、算术电路复杂性新下界、量子平行重复定理、最近向量问题的多项式因子近似难度证明、埃尔哈特体积猜想、多色拉姆齐数的超指数下界以及极值数猜想。

rss · 36氪 · 8月3日 02:57

**背景**: Astra 是 OpenAI 即将推出的模型，基于 GPT‑5.6 系列，Sol API 价格为每百万输入 token 5 美元、每百万输出 token 30 美元。通过将使用的 token 数量乘以这些费率来估算算力成本。Sol API 价格反映了运行大型模型所需的计算资源，使得 2000 美元成为研究人员可衡量的指标。
